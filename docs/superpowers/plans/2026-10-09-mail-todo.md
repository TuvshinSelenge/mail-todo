# zan (Email-to-Todo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Email yourself `todo: …` lines from Gmail; they land in a Google Sheet via Apps Script and show up on a dark, Bleach-accented web page on GitHub Pages, where you can check them off or delete them.

**Architecture:**
- **Backend:** a standalone Google Apps Script project, pushed with clasp. A 1-minute trigger parses new self-sent emails into a Google Sheet, and a web-app endpoint (secret-key protected) lists, toggles and deletes todos. Pure logic (parsing, message processing, request handling) is kept free of Google APIs, so Node can unit-test it.
- **Frontend:** a static plain-JS page (no build step) deployed from `web/` by a GitHub Actions workflow.

**Tech Stack:** Google Apps Script (V8), Google Sheets, `@google/clasp@2.4.2`, plain HTML/CSS/JS, Node 22 `node:test`, GitHub Pages + Actions, `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-10-09-mail-todo-design.md`

## Global Constraints

- No npm runtime dependencies. Tests use only `node:test` and `node:assert/strict` (Node 22.12 is installed).
- Apps Script files use plain JavaScript that runs on V8. Every `apps-script/*.js` file ends with `if (typeof module !== 'undefined') module.exports = {…};` so Node can require it. Top-level names must be unique across all Apps Script files, because they share one global scope.
- Script time zone: `Europe/Vienna`.
- Dates in data: `due` is `YYYY-MM-DD` or `''`. `created` and `doneAt` are `Date#toISOString()` strings or `''`.
- Colors: bg `#0a0a0a`, text `#ededed`, hairline `#161616`, accent `#ff6b1a`, overdue `#ff4d4d`, synced dot `#3ddc84`. Font: Inter, with a system-ui fallback.
- Todo text is rendered **only** via `textContent`, never `innerHTML`.
- `localStorage` keys: `zan.key` and `zan.todos`. Every access is wrapped in try/catch.
- User-facing copy (exact):
  - status: `Synced`, `Syncing…`, `Offline`
  - toast: `Couldn’t sync, try again`
  - wrong key: `That key didn’t work. Try again.`
  - counts: `N open · M done`
- API errors: `unauthorized`, `not_found`, `bad_request`, `server_error`. The API returns HTTP 200 with JSON `{ok:false,error}`.
- Gmail query: `from:me to:me todo newer_than:2d`. Label: `todo-saved`.
- GitHub account: `TuvshinSelenge`. Repo: `mail-todo` (public). Site: `https://tuvshinselenge.github.io/mail-todo/`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Todo text containing HTML** (`<img src=x onerror=alert(1)>`) must show as literal text and never execute. Covered by the mock data row in Task 5 plus the Task 5 manual check.
2. **Todo text starting with `=`, `+`, `-` or `@`** (e.g. `-call mom`, `=SUM(1)`) must be stored as text, not as a Sheets formula. Covered by the `sheetSafe_` test in Task 2.
3. **A reply in a thread that was already processed** (e.g. "Re: todo: x" containing a new `todo:` line) must still import the new line. Covered by the Inbox test in Task 2.
4. **Windows line endings and trailing spaces** in email bodies must parse the same as `\n`. Covered by the parse test in Task 1.
5. **Checking off a todo while a background refresh is in flight** must not snap back to the old state. Covered by the version guard in `app.js` plus the Task 5 manual check with `MOCK_DELAY_MS=3000`.

```js
// Pure parsing of "todo:" lines and trailing due dates. No Google APIs here,
// so this file runs both in Apps Script and in Node tests.

const TODO_LINE = /^\s*todo\s*:\s*(.*)$/i;
// Groups: 1 whole date token, 2 day, 3 separator, 4 month, 5 year (optional).
const DUE_TAIL = /\s+due(?:\s+to)?\s*:?\s*(today|tomorrow|(\d{1,2})([./-])(\d{1,2})(?:\3(\d{4}))?)\s*$/i;

function pad2_(n) {
  return (n < 10 ? '0' : '') + n;
}

function toIso_(y, m, d) {
  return y + '-' + pad2_(m) + '-' + pad2_(d);
}

function isRealDate_(y, m, d) {
  if (m < 1 || m > 12 || d < 1) return false;
  return d <= new Date(Date.UTC(y, m, 0)).getUTCDate();
}

function addDays_(iso, n) {
  const [y, m, d] = iso.split('-').map(Number);
  const dt = new Date(Date.UTC(y, m - 1, d + n));
  return toIso_(dt.getUTCFullYear(), dt.getUTCMonth() + 1, dt.getUTCDate());
}

function parseDue(text, todayIso) {
  const match = DUE_TAIL.exec(text);
  if (!match) return { text: text, due: '' };
  const head = text.slice(0, match.index).trim();
  if (!head) return { text: text, due: '' };

  const word = match[1].toLowerCase();
  if (word === 'today') return { text: head, due: todayIso };
  if (word === 'tomorrow') return { text: head, due: addDays_(todayIso, 1) };

  const day = Number(match[2]);
  const month = Number(match[4]);
  let year;
  if (match[5]) {
    year = Number(match[5]);
  } else {
    year = Number(todayIso.slice(0, 4));
    if (toIso_(year, month, day) < todayIso) year += 1;
  }
  if (!isRealDate_(year, month, day)) return { text: text, due: '' };
  return { text: head, due: toIso_(year, month, day) };
}

function parseEmail(subject, body, todayIso) {
  const lines = [String(subject || '')].concat(String(body || '').split(/\r?\n/));
  const out = [];
  lines.forEach((line) => {
    if (/^\s*>/.test(line)) return;
    const match = TODO_LINE.exec(line);
    if (!match) return;
    const text = match[1].trim();
    if (!text) return;
    out.push(parseDue(text, todayIso));
  });
  return out;
}

if (typeof module !== 'undefined') module.exports = { parseEmail, parseDue };
```

```js
// Google Sheet storage. Two tabs: "Todos" (one row per todo) and "Processed"
// (Gmail message ids already handled). All columns are plain text.

const TODO_HEADERS = ['id', 'text', 'due', 'done', 'created', 'doneAt', 'messageId'];
const PROCESSED_HEADERS = ['messageId', 'processedAt'];

// Leading = + - @ would make Sheets treat the value as a formula.
function sheetSafe_(text) {
  return /^[=+\-@]/.test(text) ? "'" + text : text;
}

function spreadsheet_() {
  const id = PropertiesService.getScriptProperties().getProperty('SHEET_ID');
  if (!id) throw new Error('SHEET_ID not set: run setup()');
  return SpreadsheetApp.openById(id);
}

function sheet_(name, headers) {
  const ss = spreadsheet_();
  let sh = ss.getSheetByName(name);
  if (!sh) {
    sh = ss.insertSheet(name);
    sh.getRange('A:Z').setNumberFormat('@');
    sh.getRange(1, 1, 1, headers.length).setValues([headers]);
    sh.setFrozenRows(1);
  }
  return sh;
}

function todosSheet_() {
  return sheet_('Todos', TODO_HEADERS);
}

function processedSheet_() {
  return sheet_('Processed', PROCESSED_HEADERS);
}

function cellText_(v, dateOnly) {
  if (v instanceof Date) {
    return dateOnly ? Utilities.formatDate(v, Session.getScriptTimeZone(), 'yyyy-MM-dd') : v.toISOString();
  }
  return v === null || v === undefined ? '' : String(v);
}

function isTrue_(v) {
  return v === true || String(v).toUpperCase() === 'TRUE';
}

function rowToTodo_(r) {
  return {
    id: cellText_(r[0]),
    text: cellText_(r[1]),
    due: cellText_(r[2], true),
    done: isTrue_(r[3]),
    created: cellText_(r[4]),
    doneAt: cellText_(r[5]),
    messageId: cellText_(r[6]),
  };
}

function todoToRow_(t) {
  return [t.id, sheetSafe_(t.text), t.due, t.done ? 'TRUE' : 'FALSE', t.created, t.doneAt, t.messageId];
}

function storeListTodos() {
  return todosSheet_()
    .getDataRange()
    .getValues()
    .slice(1)
    .filter((r) => r[0] !== '')
    .map(rowToTodo_);
}

function storeAddTodos(todos) {
  if (!todos.length) return;
  const sh = todosSheet_();
  sh.getRange(sh.getLastRow() + 1, 1, todos.length, TODO_HEADERS.length).setValues(todos.map(todoToRow_));
}

function findTodoRow_(sh, id) {
  const last = sh.getLastRow();
  if (last < 2) return -1;
  const ids = sh.getRange(2, 1, last - 1, 1).getValues();
  for (let i = 0; i < ids.length; i++) {
    if (String(ids[i][0]) === id) return i + 2;
  }
  return -1;
}

function storeToggleTodo(id, nowIso) {
  const sh = todosSheet_();
  const row = findTodoRow_(sh, id);
  if (row < 0) return false;
  const done = !isTrue_(sh.getRange(row, 4).getValue());
  sh.getRange(row, 4).setValue(done ? 'TRUE' : 'FALSE');
  sh.getRange(row, 6).setValue(done ? nowIso : '');
  return true;
}

function storeDeleteTodo(id) {
  const sh = todosSheet_();
  const row = findTodoRow_(sh, id);
  if (row < 0) return false;
  sh.deleteRow(row);
  return true;
}

function storeProcessedIds() {
  const sh = processedSheet_();
  const last = sh.getLastRow();
  const ids = {};
  if (last < 2) return ids;
  sh.getRange(2, 1, last - 1, 1).getValues().forEach((r) => { ids[String(r[0])] = true; });
  return ids;
}

function storeMarkProcessed(id) {
  processedSheet_().appendRow([id, new Date().toISOString()]);
}

if (typeof module !== 'undefined') module.exports = { sheetSafe_ };
```

- [ ] **Step 4: Implement `apps-script/Inbox.js`**

```js
// Turns self-sent Gmail messages with "todo:" lines into Todos rows.
// processMessages is pure (all effects via deps) so Node can test it;
// checkInbox wires it to Gmail, the Sheet and Script Properties.

const GMAIL_QUERY = 'from:me to:me todo newer_than:2d';
const LABEL_NAME = 'todo-saved';
const MAX_FAILURES = 3;

function extractEmail(from) {
  const match = /<([^>]+)>/.exec(from || '');
  return (match ? match[1] : String(from || '')).trim().toLowerCase();
}

function processMessages(messages, deps) {
  let added = 0;
  messages.forEach((msg) => {
    if (deps.isProcessed(msg.id)) return;
    try {
      if (extractEmail(msg.from) !== deps.ownerEmail.toLowerCase()) {
        deps.markProcessed(msg.id);
        return;
      }
      const items = parseEmail(msg.subject, msg.getBody(), deps.todayIso(msg.date));
      const created = msg.date.toISOString();
      deps.addTodos(items.map((item) => ({
        id: deps.newId(),
        text: item.text,
        due: item.due,
        done: false,
        created: created,
        doneAt: '',
        messageId: msg.id,
      })));
      deps.markProcessed(msg.id);
      deps.failures.clear(msg.id);
      added += items.length;
    } catch (err) {
      deps.log('Failed to process ' + msg.id + ': ' + err);
      if (deps.failures.inc(msg.id) >= MAX_FAILURES) {
        deps.markProcessed(msg.id);
        deps.failures.clear(msg.id);
      }
    }
  });
  return added;
}

function checkInbox() {
  const lock = LockService.getScriptLock();
  if (!lock.tryLock(20000)) return;
  try {
    const processed = storeProcessedIds();
    const threads = GmailApp.search(GMAIL_QUERY, 0, 50);
    const messages = [];
    const touched = [];
    threads.forEach((thread) => {
      const fresh = thread.getMessages().filter((m) => !processed[m.getId()]);
      if (!fresh.length) return;
      touched.push(thread);
      fresh.forEach((m) => {
        messages.push({ id: m.getId(), from: m.getFrom(), subject: m.getSubject(), getBody: () => m.getPlainBody(), date: m.getDate() });
      });
    });
    if (!messages.length) return;

    const tz = Session.getScriptTimeZone();
    const props = PropertiesService.getScriptProperties();
    processMessages(messages, {
      ownerEmail: Session.getEffectiveUser().getEmail(),
      isProcessed: (id) => !!processed[id],
      markProcessed: (id) => { storeMarkProcessed(id); processed[id] = true; },
      addTodos: storeAddTodos,
      failures: {
        inc: (id) => {
          const n = Number(props.getProperty('fail:' + id) || 0) + 1;
          props.setProperty('fail:' + id, String(n));
          return n;
        },
        clear: (id) => props.deleteProperty('fail:' + id),
      },
      todayIso: (date) => Utilities.formatDate(date, tz, 'yyyy-MM-dd'),
      newId: () => Utilities.getUuid(),
      log: (m) => console.error(m),
    });

    const label = GmailApp.getUserLabelByName(LABEL_NAME) || GmailApp.createLabel(LABEL_NAME);
    touched.forEach((thread) => thread.addLabel(label));
```

```js
// Web-app endpoint. handleRequest is pure; doGet/doPost wire it to the Sheet.
// Apps Script cannot set HTTP status codes, so errors are {ok:false, error}.
// POST bodies are sent as text/plain JSON to avoid a CORS preflight.

const ALLOWED_ACTIONS = { GET: ['list'], POST: ['toggle', 'delete'] };

function handleRequest(method, req, deps) {
  req = req || {};
  if (!deps.secret || typeof req.key !== 'string' || req.key !== deps.secret) {
    return { ok: false, error: 'unauthorized' };
  }
  if ((ALLOWED_ACTIONS[method] || []).indexOf(req.action) === -1) {
    return { ok: false, error: 'bad_request' };
  }
  if (req.action === 'list') return { ok: true, todos: deps.list() };
  if (typeof req.id !== 'string' || !req.id) return { ok: false, error: 'bad_request' };
  const found = req.action === 'toggle' ? deps.toggle(req.id) : deps.remove(req.id);
  return found ? { ok: true } : { ok: false, error: 'not_found' };
}

function doGet(e) {
  return respond_('GET', (e && e.parameter) || {});
}

function doPost(e) {
  let body;
  try {
    body = JSON.parse(e.postData.contents);
  } catch (err) {
    return json_({ ok: false, error: 'bad_request' });
  }
  return respond_('POST', body);
}

function respond_(method, req) {
  const lock = LockService.getScriptLock();
  let result;
  try {
    if (method === 'POST') lock.waitLock(10000);
    result = handleRequest(method, req, {
      secret: PropertiesService.getScriptProperties().getProperty('SECRET_KEY') || '',
      list: storeListTodos,
      toggle: (id) => storeToggleTodo(id, new Date().toISOString()),
      remove: storeDeleteTodo,
    });
  } catch (err) {
    console.error(err);
    result = { ok: false, error: 'server_error' };
  } finally {
    if (method === 'POST') lock.releaseLock();
  }
  return json_(result);
}

function json_(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}

if (typeof module !== 'undefined') module.exports = { handleRequest };
```

```js
// Pure display helpers shared by the page (window.ZanLogic) and Node tests.
(function (root, factory) {
  const api = factory();
  if (typeof module === 'object' && module.exports) module.exports = api;
  else root.ZanLogic = api;
})(this, function () {
  const DAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
  const LONG_DAYS = ['Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday'];
  const MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
  const LONG_MONTHS = ['January', 'February', 'March', 'April', 'May', 'June', 'July', 'August', 'September', 'October', 'November', 'December'];
  const NEW_MS = 10 * 60 * 1000;

  const pad2 = (n) => (n < 10 ? '0' : '') + n;

  function localIso(date) {
    return date.getFullYear() + '-' + pad2(date.getMonth() + 1) + '-' + pad2(date.getDate());
  }

  function longDate(date) {
    return LONG_DAYS[date.getDay()] + ', ' + LONG_MONTHS[date.getMonth()] + ' ' + date.getDate();
  }

  function isoParts(iso) {
    const [y, m, d] = iso.split('-').map(Number);
    return { y, m, d, dow: new Date(Date.UTC(y, m - 1, d)).getUTCDay() };
  }

  function shortDate(iso, todayIso) {
    const p = isoParts(iso);
    const s = MONTHS[p.m - 1] + ' ' + p.d;
    return iso.slice(0, 4) === todayIso.slice(0, 4) ? s : s + ', ' + p.y;
  }

  function dueInfo(due, todayIso) {
    if (!due) return null;
    if (due < todayIso) return { label: 'Overdue · ' + shortDate(due, todayIso), tone: 'over' };
    if (due === todayIso) return { label: 'Due today', tone: 'today' };
    return { label: 'Due ' + DAYS[isoParts(due).dow] + ', ' + shortDate(due, todayIso), tone: 'future' };
  }

  function relativeTime(iso, now) {
    const t = Date.parse(iso);
    if (isNaN(t)) return '';
    const mins = Math.floor((now.getTime() - t) / 60000);
    if (mins < 1) return 'just now';
    if (mins < 60) return mins + ' min ago';
    const hours = Math.floor(mins / 60);
    if (hours < 24) return hours + ' h ago';
    if (hours < 48) return 'yesterday';
    const d = new Date(t);
    const s = MONTHS[d.getMonth()] + ' ' + d.getDate();
    return d.getFullYear() === now.getFullYear() ? s : s + ', ' + d.getFullYear();
  }

  function isNew(iso, now) {
    const t = Date.parse(iso);
    return !isNaN(t) && now.getTime() - t < NEW_MS;
  }

  // ISO strings from toISOString() sort correctly as plain strings.
  const desc = (x, y) => ((x || '') < (y || '') ? 1 : (x || '') > (y || '') ? -1 : 0);

  function sortTodos(todos) {
    const open = todos.filter((t) => !t.done);
    const done = todos.filter((t) => t.done);
    open.sort((a, b) => {
      if (a.due && b.due) return a.due < b.due ? -1 : a.due > b.due ? 1 : desc(a.created, b.created);
      if (a.due) return -1;
      if (b.due) return 1;
      return desc(a.created, b.created);
    });
    done.sort((a, b) => desc(a.doneAt, b.doneAt));
    return { open, done };
  }

  return { localIso, longDate, dueInfo, relativeTime, isNew, sortTodos };
});
```

```js
// UI: renders todos, talks to the Apps Script API, keeps a local cache.
// Changes are applied optimistically and reverted if the API call fails.
(() => {
  'use strict';

  const L = window.ZanLogic;
  const API_URL = window.ZAN_API_URL || '';
  const KEY_STORE = 'zan.key';
  const CACHE_STORE = 'zan.todos';
  const REFRESH_MS = 60 * 1000;
  const SLASH_MS = 300;
  const STATUS_TEXT = { synced: 'Synced', syncing: 'Syncing…', offline: 'Offline' };

  const $ = (id) => document.getElementById(id);
  const els = {
    app: $('app'),
    keyScreen: $('key-screen'),
    keyForm: $('key-form'),
    keyInput: $('key-input'),
    keyError: $('key-error'),
    status: $('status'),
    statusText: $('status-text'),
    date: $('today-date'),
    counts: $('counts'),
    openList: $('open-list'),
    doneList: $('done-list'),
    openCount: $('open-count'),
    doneCount: $('done-count'),
    doneSection: $('done-section'),
    empty: $('empty'),
    toast: $('toast'),
  };

  let todos = [];
  let pending = 0; // mutations in flight
  let version = 0; // bumps on every local change; stale refreshes are dropped
  let refreshing = null;
  let toastTimer = null;

  const storage = {
    get(k) { try { return localStorage.getItem(k); } catch { return null; } },
    set(k, v) { try { localStorage.setItem(k, v); } catch { /* storage unavailable */ } },
    remove(k) { try { localStorage.removeItem(k); } catch { /* storage unavailable */ } },
  };

  // --- API ---------------------------------------------------------------

  async function apiGet(key) {
    if (!API_URL) throw new Error('no api url');
    const sep = API_URL.includes('?') ? '&' : '?';
    const res = await fetch(`${API_URL}${sep}action=list&key=${encodeURIComponent(key)}`);
    return res.json();
  }

  async function apiPost(key, body) {
    if (!API_URL) throw new Error('no api url');
    const res = await fetch(API_URL, {
      method: 'POST',
      headers: { 'Content-Type': 'text/plain;charset=utf-8' },
      body: JSON.stringify({ key, ...body }),
    });
    return res.json();
  }

  // --- State -------------------------------------------------------------

  function setStatus(state) {
    els.status.dataset.state = state;
    els.statusText.textContent = STATUS_TEXT[state];
  }

  function saveCache() {
    storage.set(CACHE_STORE, JSON.stringify(todos));
  }

  function loadCache() {
    try {
      const cached = JSON.parse(storage.get(CACHE_STORE) || '[]');
      return Array.isArray(cached) ? cached : [];
    } catch {
      return [];
    }
  }

  function showKeyScreen(message) {
    els.app.hidden = true;
    els.keyScreen.hidden = false;
    els.keyError.textContent = message || '';
    els.keyInput.value = '';
    els.keyInput.focus();
  }

  function showApp() {
    els.keyScreen.hidden = true;
    els.app.hidden = false;
  }

  function lockOut() {
    storage.remove(KEY_STORE);
    storage.remove(CACHE_STORE);
    todos = [];
    showKeyScreen('That key didn’t work. Try again.');
  }

  function refresh() {
    if (!refreshing) refreshing = doRefresh().finally(() => { refreshing = null; });
    return refreshing;
  }

  async function doRefresh() {
    const key = storage.get(KEY_STORE);
    if (!key) return;
    const startVersion = version;
    setStatus('syncing');
    try {
      const res = await apiGet(key);
      if (!res.ok) {
        if (res.error === 'unauthorized') return lockOut();
        throw new Error(res.error);
      }
      setStatus('synced');
      if (pending > 0 || version !== startVersion) return; // a local change happened meanwhile
      todos = res.todos;
      saveCache();
      render();
    } catch {
      setStatus('offline');
    }
  }

  async function mutate(body, revert) {
    const key = storage.get(KEY_STORE);
    pending++;
    version++;
    saveCache();
    render();
    try {
      const res = await apiPost(key, body);
      if (res.ok || (body.action === 'delete' && res.error === 'not_found')) return;
      if (res.error === 'unauthorized') return lockOut();
      throw new Error(res.error);
    } catch {
      revert();
      version++;
      saveCache();
      render();
      showToast('Couldn’t sync, try again');
    } finally {
      pending--;
    }
  }

  function toggle(id) {
    const t = todos.find((x) => x.id === id);
    if (!t) return;
    const prev = { done: t.done, doneAt: t.doneAt };
    t.done = !t.done;
    t.doneAt = t.done ? new Date().toISOString() : '';
    mutate({ action: 'toggle', id }, () => Object.assign(t, prev));
  }

  function remove(id) {
    const i = todos.findIndex((x) => x.id === id);
    if (i < 0) return;
    const [t] = todos.splice(i, 1);
    mutate({ action: 'delete', id }, () => todos.splice(Math.min(i, todos.length), 0, t));
  }

  function onCheck(row, t) {
    if (row.classList.contains('slashing')) return;
    if (t.done) return toggle(t.id);
    row.classList.add('slashing');
    setTimeout(() => toggle(t.id), SLASH_MS);
  }

  // --- Rendering ---------------------------------------------------------

  function el(tag, className, text) {
    const node = document.createElement(tag);
    if (className) node.className = className;
    if (text != null) node.textContent = text;
    return node;
  }

  function renderRow(t, todayIso, now) {
    const li = el('li', 'row');
    li.dataset.id = t.id;
    if (t.done) li.classList.add('done');
    else if (L.isNew(t.created, now)) li.classList.add('new');

    const inner = el('div', 'row-inner');

    const chk = el('button', 'chk');
    chk.type = 'button';
    chk.setAttribute('aria-label', t.done ? 'Mark as open' : 'Mark as done');
    chk.setAttribute('aria-pressed', String(t.done));
    chk.addEventListener('click', () => onCheck(li, t));

    const body = el('div', 'body');
    const meta = el('div', 'meta');
    const due = t.done ? null : L.dueInfo(t.due, todayIso);
    if (due) meta.append(el('span', `due ${due.tone}`, due.label), ' · ');
    meta.append(t.done ? `done ${L.relativeTime(t.doneAt, now)}` : `from email · ${L.relativeTime(t.created, now)}`);
    body.append(el('div', 'tx', t.text), meta);

    const del = el('button', 'del', '✕');
    del.type = 'button';
    del.setAttribute('aria-label', 'Delete');
    del.addEventListener('click', () => remove(t.id));

    const swipeDel = el('button', 'swipe-del', 'Delete');
    swipeDel.type = 'button';
    swipeDel.addEventListener('click', () => remove(t.id));

    inner.append(chk, body, del);
    li.append(inner, swipeDel);
    addSwipe(li);
    return li;
  }

  function addSwipe(li) {
    let x0 = null;
    let y0 = null;
    li.addEventListener('touchstart', (e) => {
      x0 = e.touches[0].clientX;
      y0 = e.touches[0].clientY;
    }, { passive: true });
    li.addEventListener('touchmove', (e) => {
      if (x0 === null) return;
      const dx = e.touches[0].clientX - x0;
      const dy = e.touches[0].clientY - y0;
      if (Math.abs(dx) < 30 || Math.abs(dx) < Math.abs(dy)) return;
      if (dx < 0) {
        closeSwipes(li);
        li.classList.add('swiped');
      } else {
        li.classList.remove('swiped');
      }
      x0 = null;
    }, { passive: true });
    li.addEventListener('touchend', () => { x0 = null; });
  }

  function closeSwipes(except) {
    document.querySelectorAll('.row.swiped').forEach((r) => {
      if (r !== except) r.classList.remove('swiped');
    });
  }

  function render() {
    const now = new Date();
    const todayIso = L.localIso(now);
    const { open, done } = L.sortTodos(todos);
    els.date.textContent = L.longDate(now);
    els.counts.textContent = `${open.length} open · ${done.length} done`;
    els.openCount.textContent = open.length;
    els.doneCount.textContent = done.length;
    els.openList.replaceChildren(...open.map((t) => renderRow(t, todayIso, now)));
    els.doneList.replaceChildren(...done.map((t) => renderRow(t, todayIso, now)));
    els.doneSection.hidden = done.length === 0;
    els.empty.hidden = open.length > 0;
  }

  function showToast(message) {
    els.toast.textContent = message;
    els.toast.classList.add('show');
    clearTimeout(toastTimer);
    toastTimer = setTimeout(() => els.toast.classList.remove('show'), 3000);
  }

  // --- Init --------------------------------------------------------------

  els.keyForm.addEventListener('submit', (e) => {
    e.preventDefault();
    const key = els.keyInput.value.trim();
    if (!key) return;
    storage.set(KEY_STORE, key);
    showApp();
    render();
    refresh();
  });

  document.addEventListener('touchstart', (e) => {
    if (!e.target.closest('.row.swiped')) closeSwipes(null);
  }, { passive: true });
  window.addEventListener('focus', refresh);
  document.addEventListener('visibilitychange', () => {
    if (document.visibilityState === 'visible') refresh();
  });
  setInterval(() => {
    if (document.visibilityState === 'visible') refresh();
  }, REFRESH_MS);

  if (storage.get(KEY_STORE)) {
    todos = loadCache();
    showApp();
    render();
    refresh();
  } else {
    showKeyScreen();
  }
})();
```

```js
// Serves web/ plus a fake API at /api so the UI can be checked locally.
// Env: PORT (8787), MOCK_DELAY_MS (0), MOCK_FAIL_WRITES=1 (writes return server_error).
import http from 'node:http';
import { readFile } from 'node:fs/promises';
import { extname, join, normalize } from 'node:path';

const WEB = fileURLToPath(new URL('../web/', import.meta.url));
const PORT = Number(process.env.PORT || 8787);
const DELAY = Number(process.env.MOCK_DELAY_MS || 0);
const FAIL_WRITES = process.env.MOCK_FAIL_WRITES === '1';
const KEY = 'test';
const TYPES = { '.html': 'text/html; charset=utf-8', '.css': 'text/css', '.js': 'text/javascript' };

const day = (offset) => {
  const d = new Date();
  d.setDate(d.getDate() + offset);
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
};
const ago = (min) => new Date(Date.now() - min * 60000).toISOString();

let todos = [
  { id: '1', text: 'Library book', due: day(-1), done: false, created: ago(60 * 30), doneAt: '', messageId: 'm1' },
  { id: '2', text: 'Buy milk', due: day(0), done: false, created: ago(2), doneAt: '', messageId: 'm2' },
  { id: '3', text: 'Homework', due: day(6), done: false, created: ago(60), doneAt: '', messageId: 'm3' },
  { id: '4', text: 'Call mom', due: '', done: false, created: ago(60 * 26), doneAt: '', messageId: 'm4' },
  { id: '5', text: '<img src=x onerror=alert(1)> should show as text', due: '', done: false, created: ago(300), doneAt: '', messageId: 'm5' },
  { id: '6', text: 'Pay rent', due: '', done: true, created: ago(60 * 48), doneAt: ago(60 * 20), messageId: 'm6' },
];

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
const json = (res, obj) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify(obj));
};

http.createServer(async (req, res) => {
  const url = new URL(req.url, `http://${req.headers.host}`);

  if (url.pathname === '/api') {
    await sleep(DELAY);
    if (req.method === 'GET') {
      if (url.searchParams.get('key') !== KEY) return json(res, { ok: false, error: 'unauthorized' });
      return json(res, { ok: true, todos });
    }
    let raw = '';
    for await (const chunk of req) raw += chunk;
    let body;
    try { body = JSON.parse(raw); } catch { return json(res, { ok: false, error: 'bad_request' }); }
    if (body.key !== KEY) return json(res, { ok: false, error: 'unauthorized' });
    if (FAIL_WRITES) return json(res, { ok: false, error: 'server_error' });
    const t = todos.find((x) => x.id === body.id);
    if (!t) return json(res, { ok: false, error: 'not_found' });
    if (body.action === 'toggle') {
      t.done = !t.done;
      t.doneAt = t.done ? new Date().toISOString() : '';
    } else if (body.action === 'delete') {
      todos = todos.filter((x) => x !== t);
    } else {
      return json(res, { ok: false, error: 'bad_request' });
    }
    return json(res, { ok: true });
  }

  if (url.pathname === '/config.js') {
    res.writeHead(200, { 'Content-Type': 'text/javascript' });
    return res.end("window.ZAN_API_URL = '/api';");
  }

  const file = normalize(join(WEB, url.pathname === '/' ? 'index.html' : url.pathname));
  if (!file.startsWith(WEB)) {
    res.writeHead(403);
    return res.end();
  }
  try {
    const data = await readFile(file);
    res.writeHead(200, { 'Content-Type': TYPES[extname(file)] || 'application/octet-stream' });
    res.end(data);
  } catch {
    res.writeHead(404);
    res.end('Not found');
  }
}).listen(PORT, () => console.log(`Mock: http://localhost:${PORT}  (key: ${KEY})`));
```

````markdown
# zan

Email yourself `todo: …` from Gmail → it shows up at https://tuvshinselenge.github.io/mail-todo/

## Writing todos

Send an email **from your Gmail to your Gmail**. Every line (subject or body) starting with `todo:` becomes a todo:

```
todo: buy milk
todo: homework due to 15.10.2026
todo: pay rent due tomorrow
```

Due formats: `due` / `due to` / `due:` followed by `DD.MM.YYYY`, `DD/MM/YYYY`, `DD-MM-YYYY`, `DD.MM`, `today` or `tomorrow`.
It takes up to ~2 minutes to appear.
````
